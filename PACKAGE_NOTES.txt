StudentHub package notes

The following local/runtime files are NOT included:
- .env
- database/database.sqlite
- storage/logs/laravel.log
- .phpunit.result.cache

Fresh installation:
1. Install dependencies with `composer install`.
2. Copy `.env.example` to `.env`.
3. Generate the application key with `php artisan key:generate`.
4. Run migrations with `php artisan migrate`.
5. Seed the database with `php artisan db:seed`.
6. Create an administrator with `php artisan make:admin` (follow the prompts).

For an existing installation, keep a private backup of your database and .env before applying migrations. Do not replace production data with local demo data.
